# 후보 장부

## 설명
- **무엇을 주나**: 기능들(Fishing · Up/Down · Watering · Link · Basecamp · CFG)이 순위에 올린 종목 + 대표가 보라고 한 종목 + 대표가 고른 추천 종목을 하루 한 번 쌓는 장부 — 어디에 있고, 어떻게 넣고 빼나.
- **도움 될 때**: 이 종목이 언제부터 눈에 들어왔나 볼 때 · 대표가 "이거 봐 둬"라고 할 때 · 총평에서 짚은 종목에 왜 넣었나 한 줄을 남길 때 · 주간 리포트 때 오래된 것을 정리할 때.
- **생김새**
  - 쓰는 법: 매일 09:30 아침 리포트가 자동으로 그날 상위(각 기능 10위 안·Link 10위 안)를 올린다. 볼 땐 `python ledger.py list`(active 목록)만 → 필요한 종목만 `show 종목명`. 대표가 보라고 하면 `add 종목명 "이유"`, 대표가 고른 추천은 `add 종목명 "이유" --by 추천`, 왜 넣었나 한 줄은 `note`. 주간 리포트 때 순위에서 빠진 지 오래고 이유가 사라진 것만 `off 종목명 "이유"`(대표가 넣은 건 대표가 빼라 할 때만 `--daepyo`).
  - 장부의 종목(대표 요구 종목 포함)을 볼 때마다: 사실을 읽은 뒤 → 위 눈 셋의 질문. (사실은 `python eye_card.py 종목명` 한 장으로)
  - 기능들(Fishing·Up/Down·Watering·Link·Basecamp·CFG)이 순위에 올린 종목 + 대표가 보라고 한 종목 + 대표가 고른 추천 종목. 하루 한 번(아침 리포트 생성 때). 목록(`index`)만 보고 필요한 종목만 연다(원-2026-10-20-10).
  - 처음부터 박아 둘 셋(위크 2026-10-20): ① 추천(picks_log)과 섞지 않는다 — 장부에선 채점하지 않는다 ② off: 대표가 넣은 건 대표가 빼라 할 때까지 active, 기능이 올린 건 순위에서 빠지면 그날 그대로 멈추고, 주간 리포트 때 이유가 사라졌으면 off + 이유 한 줄 ③ 쓰는 곳은 새러데이 하나.

## 이유
- 대표 뜻(요지, 원-2026-10-20-10): 목록만 보고 필요한 종목만 연다 — 매번 전부 열지 않으려고 목록(index)과 날짜(days)를 가른다.

## 날짜
만든 날 2026-10-20 · 대표가 처음 말한 날 2026-10-20 · 상태: 확정 · 마지막 확인 완결 2026-10-30(포맷 · 맞대기 · 읽기 · 사담 통과 — 코드 이름 2개가 지금 코드에 있는지 맞댐)

## 적용 예
- 아침 리포트 09:30이 그날 상위를 자동으로 올린다.

## 안 맞는 때
- 추천(picks_log)과 섞지 않는다 — 장부에선 채점하지 않는다.
- 자동 아침 리포트 커밋에서 `ledger/`는 빠진다(일과/기록_올리기).
- 대체됨(10-29 코드 확인): "후보 장부(`ledger.py show`)는 ① 칸만 담는다"(10-22 밤 실전 시험 2판 메모 — 일/종목_분석 임시 칸) — 틀린 말이었다. `ledger.rows_from_report`는 Up/Down · Watering · Fishing · Basecamp · CFG에 Link(② 명단 10위 안)까지 올린다(위 생김새 첫 줄과 같음). ④ Basecamp 상위 20 · ② 다른 칸(추이 · 극단 이탈 등)에 떴나는 그 리포트에서 이름을 찾는다.

## 옛 방법 — 되돌아가지 않게
- 대체됨(→ 메모 안 남김, 2026-10-30 — 일과/아침_리포트 옛 방법 칸과 같음): 총평에서 짚은 종목은 `note`로 왜 한 줄.
