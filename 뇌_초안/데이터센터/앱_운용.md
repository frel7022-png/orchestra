## 진단할 때
- 배포판만 에러가 나고 로컬·새 가상환경 재현이 다 통과하면 대표에게 **Manage app → Reboot app**을 부탁하고, 에러가 애매하면 그 "Manage app" 로그 화면 캡처부터 요청한다(리댁트 안 된 원문이 거기 있음 — 세션은 Streamlit Cloud 로그인 불가). [옮김] 옛 claude.md 393–397 (§6-1-2)
- `Desktop/backup` 스냅샷을 Git Bash에서 robocopy로 갱신할 땐 `MSYS_NO_PATHCONV=1`을 앞에 붙인다 — 안 붙이면 `/E`가 `E:/`로 바뀌어 깨진다(`MSYS_NO_PATHCONV=1 robocopy SRC DST /E /XD .git __pycache__ /XF *.pyc`). 갱신 여부는 대표에게 확인. [옮김] 옛 메모리 `project_workflow.md` 66–69행
- "최근 작업이 뭘 깨뜨렸나" 의심엔 일반론으로 답하지 말고 **`git log -p`로 그 함수의 실제 변경을 감사한 뒤** 답한다 — 무엇이 바뀌었고 안 바뀌었는지 정확히 보이는 게 더 설득력 있고, 진짜 원인(무관한 옛 구멍)이 드러나기도 한다(2026-08-24 `watchlist_prices.csv` — claude.md엔 "커밋되는 영구 데이터"라 적혀 있었는데 한 번도 커밋된 적 없었음). 앱이 직접 쓰는 파일은 `git ls-files`로 실제 커밋 여부부터 본다.
