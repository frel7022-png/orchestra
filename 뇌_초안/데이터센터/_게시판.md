# 데이터센터 — 1층 게시판

**데이터센터 = CSV + Supabase + 세션 장부 + 앱 화면. DB만 아님.** (코드에서 "DB"는 Supabase 하나만 뜻한다 — 여기선 자료 전부.)

이 빌딩은 **무엇이 어디에 있고, 언제 어떻게 쌓이고, 어떻게 꺼내나**를 다룬다. 앱은 자료의 집합체라 앱 설명도 여기 산다(대표 원-2026-10-21-18).
층 자리: 판단(바라보는 눈·가치척도·기법·추천·운용·인식의 방) / 읽기(관측소·수급) / **데이터센터** / 바닥(도서관·사례 저장고·병원 기록·정비실 고장 절차·설계도실 코드 구조 — 여기선 가리키기만).
관측소·수급과 가르는 법: 여기는 "있다·언제 쌓이나·꺼낸다", 저기는 "뜻·함정·판단".

| 언제 펼치나 | 사무실 | 지금 사는 MD |
|---|---|---|
| 이 자료 어디 있어? 누가 언제 쌓아? 장중·확정·휴장 중 어느 시점? | `데이터_지도.md` | (껍데기 — 시연 ①로 채움) |
| 세션이 손으로 쓰는 장부(픽·CFG 태그·감시목록·종료·Claude's Read·펀드 기준가·입금 행) | `세션_장부.md` | (껍데기 — 시연 ①로 채움) |
| 패널·칸마다 대표 의도·계산·무엇이 쌓이나 | `앱_기능.md` | `보유_카드.md` · `스크리너.md` · `분석_패널.md` |
| 새로고침·Setting·캐시·갱신 순서, 매매일지 반영으로 쌓이는 길 | `앱_운용.md` | `새로고침과_캐시.md` |

MD는 이름이 정체, 사무실은 지금 주소다 — "보유_카드는 지금 앱 기능 사무실에 있다"(대표, 원-2026-10-21-21). 주소가 바뀌면 이 표와 주민센터(`../뇌관리/주민센터.md`)만 고친다.

앱을 고칠 때 걸음은 `../길/앱_고치기.md`(화면 글자 → 패널 사무실 → 설계도실 → 렌더링_함정). 걸리는 메모리(이름만): `feedback_scope_features_to_their_name` · `feedback_flag_when_tests_needed` · `feedback_explain_before_fixing_code_quality` · `feedback_structure_decisions_as_report` · `feedback_confirm_spec_before_implementing`.

헷갈릴 때 고르는 법:
- 패널이 **무엇을 거르나** → 스크리너 / **무엇을 그리나** → 분석 패널 / **언제 갱신되나** → 새로고침과 캐시
- 패널 숫자를 **어떻게 재나** → 여기 말고 `../관측소/_게시판.md`
- **세팅(숫자 집 `세팅.md`) ≠ 앱 Setting 버튼**(새로고침 한 번에, `새로고침과_캐시.md`) — 이름만 같다.

자주 가는 길: `../셀관리.md` 길 표.

꼬리표 — 옛 이름: **앱/**(설명 빌딩, 2026-10-20 생성). 기록관 "쓰는 셀: 앱/…"은 원문 보관이라 그대로 둔다 — 그 `앱/X`는 지금 `데이터센터/X`다.
