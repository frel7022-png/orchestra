# 데이터센터 — 1층 게시판
주민: C-0055 데이터센터_게시판

이 빌딩은 **무엇이 어디에 있고, 언제 어떻게 쌓이고, 어떻게 꺼내나**의 정보를 담고 있다 — 자료(CSV · Supabase · 세션 장부 · 앱 화면, DB만 아님 — 코드의 "DB"는 Supabase 하나)와 그 안 관측소의 "어떻게 재나 · 함정". 판단(뜻)은 이 빌딩에 없다 — 수급 · 바라보는 눈 · 가치척도 몫. 앱은 자료의 집합체라 앱 설명도 여기 산다(원-2026-10-21-18).

헷갈릴 때:
- 패널이 **무엇을 거르나** → 스크리너 / **무엇을 그리나** → 분석 패널 / **언제 갱신되나** → 새로고침과 캐시.
- 패널 숫자를 **어떻게 재나** → 이 표 말고 관측소.
- **세팅(숫자 집 `세팅.md`) ≠ 앱 Setting 버튼**(새로고침 한 번에 — 새로고침과 캐시) — 이름만 같다.
- MD는 이름이 정체, 사무실은 지금 주소다 — 보유_카드는 지금 앱 기능 묶음에 있다(원-2026-10-21-21). 주소가 바뀌면 이 표와 주민센터(`../뇌관리/주민센터.md`)만 고친다.
