## 탭과 섹션 순서
- **Portfolio**(`ui_portfolio_tab.render_portfolio_tab`): 요약 카드(평가손익 그리드 → Pit Stop → Today's Take·Today's Alarm·Claude's Read·일일거래) → 자산 추이 → Sectors → Up/Down → Fishing → Bench → Basecamp → Foreigner → Link(잠금) → Watering Detect → Quiet Hands → Holdings 카드.
- **Analysis**(`ui_transactions_tab.render_transactions_tab`): 최초 자본 대비 요약 → Realized P&L → P&L Actions → KOSPI 2-Track Trend → Account : Index → SamHYnix extracted → Sour Grapes → VIP vs Orchestra(new1은 펀드·new1 두 선, 세 선은 meritz 앱에만 — 2026-09-08 사용자 요청) → 누적 매수/매도 요약 → 거래 캘린더.
- **Statistics**(`ui_statistics_tab.render_statistics_tab`): Price Brackets(매도 이력 빨강·보유 파랑 짝 막대) → Top Traded.

## 앱 숫자 = 보는 시점 (대표 원-2026-10-21-03 — 몇 번의 사고를 거쳐 옛 새러데이와 확립)
- 앱은 새로고침(자동·수동·Setting)마다 코스피·코스닥·대형주·보유 현재가를 **현 시세**로 다시 받고(`portfolio_core.refresh_all_prices`, 지수는 `fetch_index_quotes`), 오늘 행을 그 값으로 덮어(`@뇌 휴장일_스냅샷_건너뜀` — 장이 안 열린 날은 안 덮음) Today's Take·Account : Index·DC/UC·Orchestra 지수·Pit Stop을 전부 다시 계산한다. 따로 저장해 둔 "하루치"를 꺼내 보여 주는 게 아니다.
- **요약 카드 "일일손익" = 그날 매도의 실현손익 합**(`render_portfolio_tab`의 `daily_pnl`, 매도 행 실현손익 Σ — 세금 차감 후). 평가 변동(보유 종목이 오늘 얼마나 움직였나)은 Today's Take의 "어제 대비"(`@뇌 어제대비_총자산`)다. 이름은 그대로(대표 2026-10-21 「바꿀 이유가 있나?」, 원-2026-10-21-11).
- 그래서 Today's Take의 DC는 "오늘 하루치 결과"가 아니라 **대표가 보는 그 시점의 DC**다 — 같은 날도 새로고침마다 바뀐다(`../데이터센터/분석_패널.md` 숫자의 뜻).
- **히스토리 CSV 행과 다른 점**: git에 들어간 `asset_history`·`index_history`·`bigcap_history`·`sector_history`의 지난 날 행은 **그 날짜의 확정 종가**로 굳힌 값이다(ingest가 `portfolio_core.compute_metrics_at_close`·`portfolio_core.confirmed_close_or_live`로 찍음). 앱이 배포 서버에서 덮는 "오늘 행"은 git에 안 올라간다(§6-1). 그래서 CSV 마지막 행을 "지금"으로 읽으면 틀린다 — 세션이 지금 숫자로 답할 땐 앱과 같은 계산을 하는 `live_check.live_snapshot`을 쓴다(`../일과/지금_숫자로_답하기.md`).
- 이 원칙을 세운 사고들(문 — 서사는 `../ARCHIVE/§6-2.md`):
  - 2026-09-11 매매일지를 낮 12:36 새로고침 시점 가격으로 반영 → asset_history에 장중 값이 그날 총자산으로 박제 → 9/14 "어제 대비"·Today's Take·DC가 왜곡(DC −1 근처). → `portfolio_core.compute_metrics_at_close`(5번째 재발)
  - 2026-09-10 과거 날짜 매매일지를 장중에 반영하다 index_history·bigcap_history 그 날짜 행이 오늘 장중 값으로 덮임(meritz) → 확정 종가 우선(4번째)
  - 2026-09-16 meritz index_history[9/16]이 장중 스냅으로 커밋된 채 남아 "코스피 0.75%인데 혼합지수 1.90%" → `portfolio_core.confirmed_close_or_live` 공유 함수(7번째)

## 라벨·색·스타일 규칙
- 섹션 헤딩은 영어, **첫 글자 대문자**(메모리 `feedback_english_labels_capitalized`). 문서·대화에선 한글 이름으로 불러도 코드 grep은 영어로.
- 상승 = 빨강(`UP_COLOR`), 하락 = 파랑(`DOWN_COLOR`), 새 것 = 초록(`NEW_COLOR`) — 국내 관례.
- 모바일 웹뷰(좁은 화면) 기준, 밝은 테마. Streamlit 기본 다크 요소(파일 업로드 등)는 라이트로 재정의.
- 자주 안 보는 패널은 expander로 접는다(Up/Down·Fishing처럼 아코디언).

## 금지
- 새 그래프·기능 옆에 설명 캡션을 붙이지 않는다(개인용) — 메모리 `feedback_no_ui_explainer_captions`. 색 범례 한 줄은 예외.
