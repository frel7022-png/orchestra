## 탭과 섹션 순서
- **Portfolio**(`ui_portfolio_tab.render_portfolio_tab`): 요약 카드(평가손익 그리드 → Pit Stop → Today's Take·Today's Alarm·Claude's Read·일일거래) → Sectors → Up/Down → Fishing → Bench → Basecamp → Foreigner → Link(잠금) → Watering Detect → Quiet Hands → Holdings 카드.
  - "자산 추이" 그래프는 **코드에 없다** — 옛 claude.md §4엔 있었지만 구현된 적 없는 문장이다(옛뇌_낡은줄 17 · 10-22 밤 `ui_portfolio_tab` grep 0). 대체됨: Portfolio 순서의 "자산 추이".
- **Analysis**(`ui_transactions_tab.render_transactions_tab`): 최초 자본 대비 요약 → Realized P&L → P&L Actions → KOSPI 2-Track Trend → Account : Index → SamHYnix extracted → Sour Grapes → VIP vs Orchestra(new1은 펀드·new1 두 선, 세 선은 meritz 앱에만 — 2026-09-08 사용자 요청) → 누적 매수/매도 요약 → 거래 캘린더.
- **Statistics**(`ui_statistics_tab.render_statistics_tab`): Price Brackets(매도 이력 빨강·보유 파랑 짝 막대) → Top Traded.
- 맨 위: Setting · 시세 새로고침 버튼 → `새로고침과_캐시.md`.

## 앱 숫자 = 보는 시점 (대표 원-2026-10-21-03 — 몇 번의 사고를 거쳐 옛 새러데이와 확립)
- 사고 2026-09-07 "혼합지수 당일(뜻 B) 0.00%": `index_history`가 `asset_history`보다 며칠 뒤처짐(앱 새로고침은 배포 서버 로컬에만 쓰여 git에 안 올라감) → `_bench_on()`이 같은 index 값끼리 빼 벤치당일 0 → 오늘이 even일로·내 계좌가 벤치보다 낮은데 빨강. **고침 셋**: ① `ingest_daily.py`가 asset 옆에서 index도 같이 찍음(lock-step — 대체됨 2026-10-29: 둘 다 15:35 `daily_close`가 매일, ingest는 계좌만 다시(원-2026-10-29-18·20)) ② `compute_index_vs_account` 안전장치 — `me`를 asset·index **공통 커버 마지막 날**까지만 자름(뒤처져도 가짜 0% even일 대신 "최신"이 며칠 묵어 보일 뿐, 회귀 `test_compute_index_vs_account_caps_me_to_index_coverage`) ③ 9/7 종가 백필·9/4 공식 종가 정정. [옮김] 옛 claude.md §6-17
- 앱은 새로고침(자동·수동·Setting)마다 코스피·코스닥·대형주·보유 현재가를 **현 시세**로 다시 받고(`portfolio_core.refresh_all_prices`, 지수는 `fetch_index_quotes`), 오늘 행을 그 값으로 덮어(`@뇌 휴장일_스냅샷_건너뜀` — 장이 안 열린 날은 안 덮음) Today's Take·Account : Index·DC/UC·Orchestra 지수·Pit Stop을 전부 다시 계산한다. 따로 저장해 둔 "하루치"를 꺼내 보여 주는 게 아니다.
- **요약 카드 "일일손익" = 그날 매도의 실현손익 합**(`render_portfolio_tab`의 `daily_pnl`, 매도 행 실현손익 Σ — 세금 차감 후). 평가 변동(보유 종목이 오늘 얼마나 움직였나)은 Today's Take의 "어제 대비"(`@뇌 어제대비_총자산`)다. 이름은 그대로(대표 2026-10-21 「바꿀 이유가 있나?」, 원-2026-10-21-11).
- 정의가 다른 숫자 쌍: Today's Take 줄1 원 = 계좌 / % = 주식 · 앱 히스토리 "어제 대비" vs live_check "어제 대비"(순수 가격). 〔일/앱_고치기 임시 칸에서 옮김 10-29〕
- 그래서 Today's Take의 DC는 "오늘 하루치 결과"가 아니라 **대표가 보는 그 시점의 DC**다 — 같은 날도 새로고침마다 바뀐다(`../데이터센터/분석_패널.md` 숫자의 뜻).
- **히스토리 CSV 행과 다른 점**: git에 들어간 `asset_history`·`index_history`·`bigcap_history`·`sector_history`의 지난 날 행은 **그 날짜의 확정 종가**로 굳힌 값이다(15:35 `daily_close` · 매매일지 때 ingest가 찍음 — 계좌는 KRX 종가 `daily_close.krx_closes`, 지수는 `portfolio_core.confirmed_close_or_live`(원-2026-10-29-18·20)). 앱이 배포 서버에서 덮는 "오늘 행"은 git에 안 올라간다(§6-1). 그래서 CSV 마지막 행을 "지금"으로 읽으면 틀린다 — 세션이 지금 숫자로 답할 땐 앱과 같은 계산을 하는 `live_check.live_snapshot`을 쓴다(`../일/지금_숫자.md`).

## 라벨·색·스타일 규칙
- **Analysis 탭**: KOSPI 2-Track Trend는 항상 펼쳐 둔다 · Account : Index는 접힌 expander(2026-09-08부터 자리 바꿈). [옮김] 옛 claude.md §4
- **"청산" 대신 "매도"/"전량매도"**(코드 주석·UI·문서 전부) — 대표 「청산은 너무 네거티브한 단어」(2026-09-16). 뜻은 그대로(사이클 끝 = 전량매도). [옮김] 옛 claude.md §6-32
- **Sectors**: 섹터 막대는 **0~40% 고정 스케일** + 목표선 + 전일 대비 변화 · 섹터를 누르면 일별 추이(0~40% y축, 원값 표시). [옮김] 옛 claude.md §4
- 섹션 헤딩은 영어, **첫 글자 대문자**(메모리 `feedback_english_labels_capitalized`). 문서·대화에선 한글 이름으로 불러도 코드 grep은 영어로.
- 상승 = 빨강(`UP_COLOR`), 하락 = 파랑(`DOWN_COLOR`), 새 것 = 초록(`NEW_COLOR`) — 국내 관례.
- 모바일 웹뷰(좁은 화면) 기준, 밝은 테마. Streamlit 기본 다크 요소(파일 업로드 등)는 라이트로 재정의.
- 자주 안 보는 패널은 expander로 접는다(Up/Down·Fishing처럼 아코디언).

## 하지 않는 것 (옛 금지)
- 새 그래프·기능 옆에 설명 글을 붙이지 않는다(개인용) — 색 범례 한 줄은 예외. 리포트의 그래프·표는 다르다: 쓰인 용어에 설명을 붙인다(원-2026-10-23-10).
- 탭·섹션을 옮기거나 지울 땐 대표 확인(사용자 요청으로 생긴 자리들이다).

## 적용 예
> 예는 규칙이 아니다.
- **보는 시점 (2026-10-21)**: Today's Take의 "DC 0.xx"가 새로고침마다 바뀌는 걸 "저장된 하루 값"으로 읽어 엇갈림 — 대표 원-2026-10-21-03으로 "앱 숫자 = 보는 시점"을 확립.
- **영어 라벨 첫 글자 (2026-09-04)**: 섹션 제목을 영어로 바꾸며 첫 글자는 늘 대문자로(옛 claude.md §4).
