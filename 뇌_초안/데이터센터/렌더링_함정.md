# 렌더링 함정 — 화면이 깨질 때

## 설명
- **무엇을 주나**: Streamlit 화면이 깨지는 꼴과 그 까닭 — 공백만 남은 줄에서 HTML이 끊기고, expander 안 그래프 폭이 0이 되고, 카드 위 버튼이 높이를 밀어낸다. 조각을 넣을 때 무엇을 확인하나.
- **도움 될 때**: 화면에 HTML 원문이 그대로 보일 때 · expander 안 그래프가 안 그려질 때 · 버튼이 카드와 겹치거나 카드가 길어질 때 · CSS가 안 먹을 때 · 새 HTML 조각·그래프를 넣을 때.
- **생김새 — 깨지는 꼴과 고치는 꼴**
  - **빈 줄 HTML 끊김**: `st.markdown(f"""…""", unsafe_allow_html=True)` 안에서 조건부로 비는 조각(`{a}{b}`)을 단독 줄에 두면, 다 비었을 때 그 줄이 공백만 남아 HTML 블록이 끊기고 뒤가 코드블록(원문 노출)이 된다. 비는 조각은 **항상 내용이 있는 태그와 같은 줄에** 이어 붙인다(`{a}{b}<div class="always-here">`). 앞뒤 줄에 내용이 있어도 안전하지 않다 — 마크다운은 그 줄 자체가 비었는지만 본다.
  - **expander 안 그래프 폭 0**: `st.plotly_chart`가 expander 안에서 폭 0으로 안 그려진다 → `components.html`(iframe) + plotly `responsive:true`. 리사이즈 루프(`Plotly.relayout`)는 넣지 않는다(렌더 프리즈).
  - **카드 위 버튼**: 카드 높이에 영향을 안 주려면 `st.container(key=…)` + CSS `position:absolute`(`[class*="st-key-…"]`).
    - 짝 함정: 그 버튼은 `position:absolute`라 흐름에서 빠져 **긴 종목명과 겹칠 수 있다** → 이름 칸 `max-width:calc(100% - 180px)` · 13px · nowrap(`app.py` 113, 옛 §6-10).
  - **한글(CJK) 글자 중간 줄바꿈**: 종목명이 `white-space:nowrap` 없이 배지 옆에 붙으면 아무 글자 사이에서나 쪼개진다("SGC에" / "너지") → 카드 종목명은 nowrap(13px · `app.py` 114) · 배지는 별도 줄(`dividend-row`) · 목록 줄 이름은 nowrap + 말줄임(`app.py` 102)(옛 §6-15 · 2026-09-01).
  - **iframe 안**은 시스템 폰트 · inline 색 — 앱 CSS가 안 먹는다.
- **어떻게 보나 — 넣을 때 물어볼 것**
  - 이 조각들이 전부 비면 이 줄이 공백만 남는가?
  - 픽셀 정렬을 눈으로 봤어? 로컬 Chrome + Playwright로 모바일 폭(390px — 데이터센터/화면_지도)에서 실제로 본다(메모리 `project_playwright_visual_check`). AppTest(`tests/test_app_smoke.py`)는 예외와 WATERING 토글 상태까지만 본다 — 픽셀 · CSS 정렬은 못 본다.
  - 비는 조각을 보기 좋게 별도 줄로 빼려는 거 아니야? 그 줄이 비는 경우가 반드시 생긴다는 전제로 짠다.
  - ⚠dtype(종목코드가 숫자로 읽혀 앞 0이 빠짐)은 렌더링이 아니라 자료 쪽 함정 — 데이터센터/새로고침과_캐시(ui_cache 종목코드 dtype=str) · 꺼내는_창구.

## 안 맞는 때
- 숫자가 틀리게 보이는 건 렌더링이 아니라 계산·시점 문제다 — 관측소·데이터센터/데이터_지도.
- 고친 뒤 배포판에만 안 보이면 렌더링이 아니라 배포 캐시일 수 있다 — 데이터센터/앱_운용(진단 꼴).
- 빈 줄 끊김은 조각이 비는 경우(신규 종목 · 데이터 없는 종목)에만 나타나서 늦게 발견됐다 — 그래서 넣을 때마다 묻는다(옛 claude.md §1-8). (옛 이유 칸에서 옮김 2026-10-30)
- 픽셀은 짐작으로 고치면 맞을 때까지 여러 번 오간다 — 눈으로 본다. (옛 이유 칸에서 옮김 2026-10-30)
