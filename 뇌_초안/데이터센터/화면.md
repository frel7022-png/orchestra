# 화면

## 설명
- **무엇을 주나**: 앱이 어떻게 보이나를 볼 때 어느 장을 열지.
- **도움 될 때**: 어느 탭·섹션에 무엇이 있나 · 새 섹션 자리·라벨·색을 정할 때 · 화면이 깨질 때(HTML 노출 · 그래프 폭 0) · 입력 폼을 넣자는 생각이 들 때.
- **이 사무실에 사는 장**
  | 이런 상황이면 | 이 장이 도움이 될 수 있어 |
  |---|---|
  | 탭·섹션 순서 · 라벨·색 규칙 · 앱 숫자 = 보는 시점 | `화면_지도.md` |
  | 화면에 HTML이 그대로 보이거나 그래프 폭이 0일 때 | `렌더링_함정.md` |
  | 입력 폼·편집 UI를 넣자는 생각이 들 때 · 섹터를 고칠 때 | `입력_원칙.md` |
