# 보유 카드 — Holdings 카드가 무엇을 보여 주나

## 설명
- **무엇을 주나**: Holdings 카드 · WATERING 상세(물타기 그래프) · 배당 배지 · 외인 보유율 배지 · 카드 색이 무엇을 보여 주고 어떻게 계산되나. 카드는 거래 기록 재생 결과를 보여 주기만 한다 — 평단가를 다시 계산하지 않고, 사이클은 "현재 보유 사이클"만 본다.
- **도움 될 때**: 카드 칸·색·배지를 고치거나 설명할 때 · "이 색 왜 이래?" · WATERING 그래프가 이상해 보일 때.
- **생김새 — 카드에 무엇이 있나**
  - 이익 종목 손익 셀의 보유 거래일수는 `index_history` 실제 거래일로 센다(휴장 반영) — 8/14 이전 구간만 월~금 근사(2026-08엔 평일 휴장이 없어 정확). [옮김] 옛 claude.md §4
  - **종목명 아래 배지 줄**(`dividend-row`): 배당수익률(구간별 색, `_dividend_badge_html`) + 외국인 보유율(`holding_foreign_map`, 세션 1회 조회). 배당은 캐시에 없는 종목만 한 번 긁는다(`refresh_dividend_yields`).
    - 배당 배지 색: 5% 초과 빨강 / 3~5% 진한 녹색 / 1~3% 검정 / 1% 미만 파랑(사용자 지정, 옛 §6-15).
    - 외인 배지 색: 높으면 녹색 / 낮으면 파랑 / 그 사이 검정, 값은 investor_flow 최신 보유율 (구간 숫자 → `세팅.md`).
    - 배당 조회는 지금도 `coinfo.naver` 스크레이핑이다(`dividend_cache.csv` 마지막 조회일 2026-09-08) — 09-14 네이버 개편 뒤로 새로 산 종목은 배지가 조용히 빠질 수 있다 (세션 값·출처 없음).
  - **손익 셀**: 이익 종목만 최초 진입일·보유 거래일수 배지 + 세금 차감 후 실현액(손익 − 평가금액×fee_rate) 병기.
    - 보유 거래일수 N은 진입일부터 오늘까지 index_history 거래일, 양 끝 포함이다 — 진입 당일이 1일. 손실 종목에 안 띄우는 이유는 기록이 없다 (세션 값·출처 없음).
    - 세금 차감 후 실현액은 fee_rate 0.2% 하나로 매도 비용 전체를 근사한다(매수 0) — "지금 다 팔면 손에 남는 순액"을 보려고 있다.
  - **카드 색**: CFG 태그 사이클 = 옅은 빨강(맨 위 고정) > 물타기(매수 2회 이상, 원-2026-10-23-04·09) 중 현재가 ≥ 최초진입가 = 옅은 파랑 > 평단 −0.5% ≤ 현재가 < 최초진입가 = 옅은 녹색(평단 −0.5% 아래는 흰색, `watering_card_state`). 오늘 처음 보유 = 맨 위·종목명 초록. **둘이 같이 있으면 CFG 빨강이 그보다도 위**(맨 위 고정) — 정렬 라디오 순서 → 오늘 신규를 위로 → CFG를 그 위로, 묶음 안 순서는 그대로(`ui_portfolio_tab.render_portfolio_tab`, 2026-10-06 사용자 지시). 〔역출제 2차 1026 — 코드 확인, 위크 채점 뒤〕 [새]
    - CFG 빨강은 열린 사이클에 CFG 매수가 하나라도 있으면 켜진다(`holding_is_cfg`) — 물을 더 타도 전량매도 전까진 빨강. 성적(Statistics CFG vs Others)도 2026-10-21부터 사이클 단위다(0f536aa — 그 전 10-06~10-20은 매수 1건 단위, 수급/외인_매수_복기 옛 방법).
    - 파랑의 뜻(대표 원-2026-10-20-20): 물타며 시드를 키웠는데 최초진입가 자리만 와도 익절 — 아무것도 안 했으면 못 버는 구간에서 번 것, 물타기 자체가 노리는 곳. 대체됨(2026-10-20): 2회 이상 + 현재가 ≥ 최초진입가 = 녹색 / 같은 날 녹색 = 평단 ±0.5%·그 위 흰색 → 흰색 구간 없앰(위크 추천에 대표 "응 너 판단대로해", 원-2026-10-20-22).
  - **타이틀 옆**: 숫자는 오늘 등락 3구간 개수다 — +1% 이상 빨강 / ±1% 회색 / −1% 이하 파랑(2026-09-16~, `@뇌 holdings_등락3구간` · 그대로 확정 원-2026-10-30-02). 대체됨: 옛 "(이익 수 / 손실 수)"(09-07). 그 옆 등락률순 정렬 점(정렬 라디오와 독립).
  - **WATERING 점** → 상세(아코디언, 하나만): 누적·이번 사이클 매수/매도 요약, 그래프(현재가 = DB 일별 종가, 평단가 = 계단선 `line_shape='hv'`, 매수 ▲·매도 ▼, 최초진입가 점선).
    - 그래프 색은 매수 ▲·평단 계단선 = 파랑(`DOWN_COLOR`), 매도 ▼ = 빨강(`UP_COLOR`), 최초진입가 = 회색 점선이다(`@뇌 물타기그래프_평단선`) — 화면 지도의 "상승 빨강·하락 파랑"과 다른 뜻으로 쓴 색. 사실 기록, 규칙인지는 대표 답 뒤.
    - 그래프 읽기: "현재가는 최초 대비 −X%, 평단은 −Y%" — 둘이 비슷하면 물타기가 현재가를 잘 따라가고 있다(claude.md §6-10 물타기 적정성 그래프, 2026-08 — 원-2026-08-21-01, 요약). 〔일/물타기_매도 임시 칸에서 옮김 10-29〕
  - Holdings 색 여섯 곳: 카드 바탕 CFG 빨강·물타기 파랑/녹색 · 종목명 색 오늘 신규 초록 · 배당 배지 · 외인 배지 · 타이틀 옆 등락 3구간 · 물타기 그래프 선. 카드 색 코드: 평단·최초진입가 `portfolio_core.get_holding_trade_points` · 경계 `watering_card_state` · `WATER_GREEN_BAND`. 〔일/앱_고치기 임시 칸에서 옮김 10-29〕
  - 계산 함수: `_current_cycle_transactions` · `get_holding_trade_summary(_all_time)` · `get_holding_trade_points` · `get_holding_avg_price_path` · `get_stock_price_history_db`.
- **생김새 — 지키는 것**
  - 배당 배지 괄호 값("1.1% (2025.12)")은 **결산연월**이지 배당락일·지급일이 아니다 — 네이버 종목분석·wisereport·모바일 API 어디에도 날짜 단위 배당락일이 없어서 대표가 "결산월로 대체"를 골랐다(2026-09-01). 정확한 배당락일이 필요해지면 KRX 등 다른 소스를 새로 찾는다. [옮김] 옛 claude.md §6-15
  - 평단가를 "총매수금 ÷ 총매수수량"으로 다시 계산하지 않는다 — 매도가 끼면 틀린다. holdings의 평단가(재생 결과)를 쓴다.
  - 전량매도 이전 사이클을 그래프·요약에 섞지 않는다(`_current_cycle_transactions`).
  - 배당 배지를 종목명 옆에 붙이지 않는다 — 항상 아래 줄. Fishing엔 배당 배지 없음.
  - 카드 그래프 시세를 네이버에서 낱개로 부르지 않는다 — DB만, 없으면 두 점 직선.

## 이유
- **WATERING을 만든 이유**(대표 10-22 마-5, 원-2026-10-22-08): 언제 물을 탔는지, 그리고 물타면서 최초진입가 대비 현재가와 내 평단의 위치를 대표가 눈으로 확인하려고 — 대표 스스로 앱에서 트래킹을 눈으로 보려는 것. 그래서 그래프는 판정이 아니라 위치를 보여 준다.
- 평단가를 다시 계산하지 않는 까닭: 매도가 끼면 "총매수금 ÷ 총매수수량"이 틀린다(2주@1000 매수 → 1주 매도 → 1주@900이면 정답 950, 단순평균 966 — 옛 claude.md §6-10).

## 안 맞는 때
- 카드 색이 다른 색과 겹친다: 녹색 카드 = 신규 종목 이름색 `NEW_COLOR` #22c55e와 같은 색, 파랑 카드 #3b82f6은 손실색 `DOWN_COLOR` #2b6cd4와 같은 계열(`@뇌 물타기_카드색`) — 볼 때 헷갈리기 쉽다.
- 카드의 CFG 빨강(사이클 기준)과 Statistics CFG vs Others(사이클 단위 성적)를 같은 줄로 읽지 않는다 — 켜지는 조건과 세는 단위를 붙여 말한다(수급/외인_매수_복기).
- 보유 종목이면 자리가 물타기·매도 판단의 첫 숫자다 · 일봉엔 거래량도 같이 본다 · 자리 %는 지금가로 다시 잰다 — 저장된 보유 현재가는 마지막 반영 때 값(애프터장일 수 있음). 〔일/종목_분석 임시 칸에서 옮김 10-29〕
