## 갈림·멈춤
- **어느 표만 비었나**:
  1. investor_flow만 → 출처 API 개편(09-10 전례) · **5영업일 넘게 비면 못 메운다**(API가 최근 5영업일만 줌). [기억]
     - 왜 하루도 비면 안 되나: Foreigner·Link·Quiet Hands·CFG가 **기준일 대비 외인 보유율 변화(기준일pp)**를 기간으로 잰다. 하루가 비면 그 기간 계산이 틀어진다 → `../수급/외인_판단.md`. 5영업일이 넘으면 API로 못 메우니 그 전에 보고한다. [기억] 〔줄보태기 — 3c `길_줄보태기_다섯.md`, 8c 넣음 10-22〕
  2. market_flow만 → 행이 있나만 본다(값 0은 휴장일 정상). [기억]
  3. **셋 다 그날 없음** → 크론이 아직 안 돌았나(16:13 전) · GitHub 스케줄 스킵(08-27). 다음 cron의 `fill_recent_gaps`(최근 5거래일 · watchlist 90% 미만이면 메움)가 price_history·market_flow를 메우고, investor_flow는 5영업일 안이면 통째 upsert로 자가 복구. cron을 정각으로 되돌리지 않는다. [기억]
     - **안 돌았나, 늦나를 가르는 입구**: GitHub Actions `daily-price-fetch.yml` 실행 이력(Actions 탭, 또는 `git credential fill` 토큰 + curl로 runs API — claude.md §6-9). 이 길로 실제로 본 마지막은 **08-25(수동 트리거)·09-01(실행 이력 조회)**이고 **지금도 되는지는 미확인**이다 — 못 보면 "실행 이력 못 봄(마지막 확인 09-01)"이라고 밝히고, 다음 cron(16:13 KST) 뒤 다시 잰다. 스케줄 지연은 자정을 넘길 수 있다(09-01 날짜 밀림). 〔시험9〕
  4. 날짜가 하루 밀림 → cron 자정 지연(09-01) · relabel 전에 그 날짜 unique 충돌부터. [기억]
  5. 휴장일인데 행이 있음 → 가짜 행(10-05). [기억]
  6. 한두 종목만 → 거래정지(**watchlist 수 −1**) · 방금 편입(investor_flow는 다음 cron 뒤). [기억]
- **빈 날은 바로 메운다** — 대표 10-22 가-1 ⓐ(원-2026-10-22-03). 묻지 않고 메우고, 출근 보고 **첫 줄**에 "어느 날 몇 종목 메웠다". 메우기(쓰기)는 승인 불요, 지우기는 아래대로 승인. [기억](옛 관행 09-14·09-29) / 대표 확정 [새]
