## 업무의 얼굴
- **경고 (a)** "휴장일 달력 확인할 때" — 확인일 **최댓값**이 **35일** 넘게 지남(확인일이 하나도 없어도 뜸 — `portfolio_core.krx_calendar_warnings`의 `stale_days`, 숫자 → `../데이터센터/세팅.md`). → 갱신 걸음. [새]
- **경고 (b)** "내년 휴장일 넣을 때" — **12월 한 달 동안만**(코드 `t.month == 12`) 다음 해 휴장일이 0줄이면. 1월로 넘어가면 새해 줄이 없어도 안 뜬다 → **1월 첫 출근 점검 땐 눈으로 한 번**. → KRX 공지로 내년 평일 휴장 넣기(전부 예정). [새]
- 경고 (c) "krx_holidays.csv를 못 읽음" → 파일 깨짐·없음 — 달력으로 못 거르는 상태라 바로 고친다(실시간 판정 보조 그물만 남음). [새]
- **새 휴장 공지**(선거 등) → 그 날짜 한 줄(예정) 바로. [재구성]
- **가짜 행이 보임** → 달력 이전 사고인가, 달력에 빠진 날인가부터(정비실/휴장일 반문 질문). [새]

## 갱신 걸음
1. 지난 확인일 이후 평일을 `fetch_daily_price_history("KOSPI", …)`와 대조 — **코스피 일별시세에 없는 평일 = 실측 휴장**. 확인 칸 "실측(…)", 확인일 = 오늘. [새]
2. 남은 해 평일 휴장은 KRX 공지로 "예정". 실측으로 바뀌면 그 줄을 고친다(줄을 지우지 않음). [새]
3. **이미 있는 줄도 확인일을 오늘로**(경고 (a)는 확인일 최댓값으로 재기 때문 — 새 휴장이 없어도 한 줄은 갱신해야 경고가 꺼진다). [재구성]
4. 테스트(`test_krx_calendar_closes_holiday_and_weekend_without_network`·`test_krx_calendar_warnings_stale_check_and_missing_next_year`·`test_market_traded_on_*` 셋) → 커밋(`셀: 정비실/휴장일`) → push. [새]

## 멈춤
- ⛔ **DB·히스토리의 가짜 행 삭제는 대표 확인 뒤** — 지우기 전 행 수를 찍고 백업(10-06 가짜 10/5 행 180개 + market_flow 0 행 2개 / 10-21 추석 복제 행 360개 + 0 행 4개, 둘 다 대표 확인 뒤). [기억] / 10-21 [새]
- 휴장일 market_flow 순매수 **0은 오류가 아니다**(9/24 추석 실측 — 새 API가 휴장일에 "0"을 줌). 0 행을 "빠진 데이터"로 오해해 다시 받지 않는다 — 단 그날 행 자체가 생긴 게 가짜면 위 멈춤으로. [기억]
- 8/27 같은 "평일인데 데이터 없음"은 **휴장이 아니라 cron 미실행**일 수 있다 — 달력에 넣지 말고 출근 점검(빠진 날 메우기)으로. [기억]
- meritz·써스데이는 아직 이 달력을 안 본다 — 이식은 그쪽 레포 일. 새러데이가 해도 되는 건 대표가 맡긴 범위만(위 D1 정정). 〔대기: meritz 이식 시점 — 대표〕 [새]
