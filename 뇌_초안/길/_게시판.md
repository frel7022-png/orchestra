# 길 — 1층 게시판

이 빌딩엔 **임무 하나 = 길 한 장**이 산다. 길은 명령이 아니라 판단이다 — "어, 이런 업무네. 저기를 먼저 가 봐야겠군"(대표 원-2026-10-21-15).
길 한 장의 꼴(도시_운용_원칙): 업무의 얼굴 → 먼저 볼 곳과 **왜 여기 먼저** → 갈림·멈춤 → 확인 → 지난 경험. 경험으로 둘째·셋째 칸을 고친다.
길엔 입구(스크립트·함수 이름)·손잡이(인자·출력에서 볼 줄)·기준(현행값 집 가리킴)만 쓴다. 코드 안에서 무엇이 어떤 순서로 불리나(외주 사슬)는 쓰지 않는다 — 그건 코드가 안다.

| 이런 말이면 | 길 |
|---|---|
| "넣었어"·"반영해"·"올렸어"(매매일지 CSV) | `매매일지_반영.md` |
| "B 어때?"·"이 종목 봐 줘" | `종목_분석.md` |

일하는 사무실(절차·금지 칸)은 길이 가리킨다 — 길이 사무실 내용을 베끼지 않는다.
