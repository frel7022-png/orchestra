# HISTORY 목록

> 셀 아님 · 평소 안 읽음. "그때 대표와 무슨 얘기를 했나·어떻게 그렇게 됐나" → 이 목록에서 날짜 한 줄 → 그날 파일 하나만.
> 하루 파일 칸: 그날의 흐름 / 물어본 것·답한 것 / 정해진 것 → 셀·번호 / 진행된 일(커밋, `python brain_log.py history 날짜`) / 남은 것 / 셀 이력 원문.
> 쓰는 때: 그날 마지막 커밋 때(16:50 묶음 전) — `../일과/기록_올리기.md`. 뼈대는 brain_log가 뽑고, 손으로는 흐름·물어본 것·남은 것만.

## 규칙 (대표 원-2026-10-20-24)
- **목적은 맥락**: 두꺼운 책 앞의 목차처럼 — 평소엔 이 목록만 읽고 "지난 동안 이런 일을 해 왔구나"를 안다. 하루 파일은 그때 정말 필요할 때만 연다.
- **목차는 영원히 남긴다**: 이 표의 날짜 한 줄은 지우지 않는다.
- **하루 파일은 3개월이 지나면 지운다 — 지우기 전에 대표에게 묻는다.** 주간 리포트 때 `python brain_log.py history-old`로 3개월 넘은 파일을 찍어 "제안"에 한 줄로 묻고, 대표가 응하면 파일만 지운다(목차 줄은 그대로, 끝에 "(파일 지움 날짜)").
- 지워도 되는 이유: 그날 대화에서 중요한 것(관점·결정·이유)은 쓰는 날 이미 골라 셀에 담았고(원-2026-10-20-23), 대표 원문은 기록관, 커밋은 git에 남는다.
