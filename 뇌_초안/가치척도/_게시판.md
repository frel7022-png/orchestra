# 가치척도 — 1층 게시판 (분석 빌딩, 가칭 — 옛 이름 기준과 비교)

이 빌딩은 **숫자를 무엇에 견주나**를 다룬다. 같은 숫자도 분모·벤치·기간이 바뀌면 뜻이 뒤집힌다는 관점 셋이 모여 있다.
대표의 "이거 왜 이래?" 질문이 가장 많이 키운 빌딩이다(원본 대표 원문 중 관점 씨앗 17개가 여기로 온다).

| 언제 펼치나 | 사무실 |
|---|---|
| 숫자 하나(등락률·외인 변화·거래량·내 수익률)가 커 보이거나 작아 보여서 판단을 내리려 할 때. 문턱(몇 % 이상)을 걸려 할 때 | `상대적_가치.md` |
| 내 계좌·종목을 무엇과 견줄지 정할 때. "시장 대비 이겼다/졌다"를 말할 때. 벤치마크를 고르거나 바꾸자는 생각이 들 때 | `누구와_싸우나.md` |
| 맞았다·틀렸다, 통했다·안 통했다를 말하려 할 때. 추천·픽·지표의 성적을 낼 때. 두 숫자의 기간이 서로 다를 수 있을 때 | `판정은_기간에_묶여_있다.md` |

헷갈릴 때 고르는 법:
- "이 숫자, 커?" → 상대적 가치
- "누구랑 비교해?" → 누구와 싸우나
- "언제부터 언제까지?" → 판정은 기간에 묶여 있다
