# 가치척도 — 1층 게시판 (분석 빌딩, 가칭 — 옛 이름 기준과 비교)
주민: C-0018 가치척도_게시판

이 빌딩은 **숫자를 무엇에 견주나**를 다룬다. 같은 숫자도 분모·벤치·기간이 바뀌면 뜻이 뒤집힌다는 관점 셋이 모여 있다.
대표의 "이거 왜 이래?" 질문이 가장 많이 키운 빌딩이다(원본 대표 원문 중 관점 씨앗 17개가 여기로 온다).

| 언제 펼치나 | 사무실 |
|---|---|
| 숫자 하나(등락률·외인 변화·거래량·내 수익률)가 커 보이거나 작아 보여서 판단을 내리려 할 때. 문턱(몇 % 이상)을 걸려 할 때 | `견주는_법.md` |
| 내 계좌·종목을 무엇과 견줄지 정할 때. "시장 대비 이겼다/졌다"를 말할 때. 벤치마크를 고르거나 바꾸자는 생각이 들 때 | `누구와_싸우나.md` |
| 한 종목·한 숫자를 **시장 전체와 견줘** "혼자 빠졌나, 다 같이 빠졌나"를 말하려 할 때 | `견주는_법.md`가 도움이 될 수 있어 — 무엇과 견줄지(그 종목이 속한 시장, 같은 기간)를 고르는 틀이 거기 있어서. 바다를 재는 법은 관측소 게시판 |
| 문턱·기준선 숫자의 지금 값을 쓰기 직전 — 이 빌딩은 틀(잣대)만, 숫자는 데이터센터 세팅 집에서 | `../데이터센터/세팅.md` (2026-10-22 이사) |
| 추천·픽·지표의 성적(맞았다·틀렸다)을 낼 때, picks_score·tracking을 읽을 때, 외인 이탈로 픽을 판정하려 할 때 | `성적_매기기.md` |

헷갈릴 때 고르는 법:
- "이 숫자, 커?" → 견주는 법
- "누구랑 비교해?" → 누구와 싸우나
- "성적이 몇이야?" → 성적 매기기 / "며칠짜리로 본 거야?" → `../바라보는_눈/판정은_기간에_의해_변화한다.md`

자주 가는 길: `../셀관리.md` 길 표(`brain_log.py links`가 만든다 — MD 규율 v1.0 §18-9).
