# 기상대 — 1층 게시판 (배경 빌딩)

이 빌딩은 **지금 바다(시장 전체)의 물살이 어느 쪽인가**를 다룬다. 다른 빌딩이 종목 하나를 보는 눈이라면, 여긴 모든 종목이 같이 달리는 바다다. 종목을 판단하다가 "시장 전체와 견주면?"이 필요할 때 건너온다(대표: "셀과 셀을 이어주는 뉴런").
국장 바다만 다룬다 — 나스닥 바다는 튜즈데이 도시의 기상대(위크 10-20: 도시마다 자기 기상대).

| 언제 펼치나 | 사무실 |
|---|---|
| 종목 판단 중 시장 전체(환율·시장 외인·주가 전체)와 견줘야 할 때, 외인 비중이 "그대로"라 지나치려 할 때, 환율·시장 외인이 크게 움직였다는 말이 나올 때 | `바다의_상태.md` |

자주 같이 가는 길:
- 바다의 상태 → `../수급/외인_판단.md` (역풍 속 상대 외인이 위쪽인 종목)
- 바다의 상태 → `../수급/바닥과_물량.md` (그 종목이 다지는 중이면)
- `../수급/외인_판단.md`·`../수급/바닥과_물량.md`·`../운용/작은_파도.md` → 바다의 상태 (종목 쪽에서 들어오는 길)
