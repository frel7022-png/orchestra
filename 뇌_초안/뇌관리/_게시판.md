# 뇌관리 — 1층 게시판
주민: C-0109 뇌관리_게시판

이 빌딩은 **도시 자체를 관리**한다 — md가 어디 살고, 어떻게 새기고, 도시가 왜 이렇게 생겼나.
> 안내다 — 순서나 의무가 아니다. 어느 사무실을 열지는 걷는 쪽이 그때 판단한다(원-2026-10-27-12). 꼴: "이런 질문·상황이면 이 사무실이 도움이 될 수 있어(왜)".

| 이런 질문·상황이면 | 이 사무실이 도움이 될 수 있어 | 왜 |
|---|---|---|
| md를 새로 만들거나 옮기려 할 때 · 어느 md가 지금 어디 사는지 찾을 때 | `주민센터.md` | 이름과 주소를 떼어 두는 곳 — 주소록(`주소록.csv`, 손으로 안 씀)이 거기서 나와서 |
| 대표가 반례·정정·결정을 말해 무언가를 새기려 할 때 · 어디에 무엇을 쓸지 헷갈릴 때 | `셀_채우기.md` | 한 곳에만 쓰고 원문과 해석을 가르는 법이 거기 있어서 |
| md 한 장을 새로 짓거나, 섞인 장을 가르거나, 다른 빌딩으로 옮기려 할 때 · 다른 도시가 우리 md를 빌려 쓸 때 | `md_포맷_설명서.md` | md 한 장에 들어갈 칸(제목·설명·이유·날짜·적용 예·안 맞는 때)과 갈래마다 읽는 법이 거기 있어서 |
| 빌딩·사무실·일 md를 새로 만들거나 고치려 할 때 · 도시가 왜 이렇게 생겼나 궁금할 때 | `도시_운용_원칙.md` | 도시가 커지고 변해도 깨지지 않게 하는 원칙이 거기 있어서 |
| "도시에 없다"라고 말하기 직전 | `find_city.py`(도구) | 낱말로 도시 전체를 한 번 찾아보는 입구라서 |
| 옛 뇌 쪽에 표시해 둔 일·옛 문구가 왜 그렇게 쓰였나 볼 때 | `_새뇌대기.md` · `_근거_목록.md` | 이관 중 임시 장부라서(이관이 끝나면 정리) |
