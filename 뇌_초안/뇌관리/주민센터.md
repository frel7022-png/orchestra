# 주민센터

## 설명
- **무엇을 주나**: MD는 도시의 주민이고 사무실은 지금 주소다 — 주민센터가 주민등록표를 들고 전입·이사 신고를 받고 주소를 알려 주고 조감도를 뗀다.
- **도움 될 때**: MD를 새로 만들거나(전입), 다른 사무실로 옮기거나(이사), 어느 MD가 지금 어디 사는지 찾을 때(주소 조회), 도시 전체 그림이 필요할 때(조감도)

- **생김새 — 주민센터가 하는 일**(2026-10-28 머리 "이 사무실 안"에서 되살림 — b8 검산)
  - **주소록(동사무소 최소판, 2026-10-27 대표 원-2026-10-27-10)** — `뇌관리/주소록.csv`(번호·이름·지금 경로). 손으로 쓰지 않는다: md의 `주민: C-NNNN 이름` 줄을 `python brain_log.py addr`가 긁어 만든다(이사하면 다시 돌림). 검사 `python brain_log.py addr --check` · CI `tests/test_address_book.py`(주소록 ↔ 파일 · 본문 속 끊긴 경로). 첫 판 = 허브 17장(대기 포함). 주민 카드 칸 전체와 경로 898개 바꿔 쓰기는 이관 뒤(U-026)
  - **옛 주소표** `뇌관리/옛_주소.csv`(손으로 씀, 2026-10-28 이사 셋부터) — 옛 이름·옛 경로로 찾아온 걸 지금 주소로 돌려 준다. 주소록(자동)엔 옛 칸이 없어서 따로 둔다.
  - 주민등록표 v0 — `Week/기획/MD설계/주민센터/주민등록표_v0.csv`(옛 claude.md 조각 281 · 지금 주소 · 확실도 — 짐작 159는 검토 전)
  - 전입·이사 신고 — 절차(git mv · 옛 자리 가리킴 · links 0)
  - 주소 조회 · 조감도 발급 — 지금은 `../셀관리.md` 지도·길 표 · 숫자 집 = `../데이터센터/세팅.md`(옛 현행값 집, 2026-10-22 이사)
  - 전입·이사 걸음(오늘 이사 셋이 쓴 꼴): `git mv`로 옮기고 → 본문 속 경로·이름을 새 주소로(기록관 원문·HISTORY·ARCHIVE 본문은 옛 이름 그대로, 살아 있는 .md 경로만) → `python brain_log.py addr`(주소록 다시) → `addr --check`·links·text_path 0 → 옛 이름·옛 경로는 `옛_주소.csv`에 한 줄.

## 이유
- 대표 「우리 도시는 컨트롤 타워가 핵심이고 그게 영리한(각자 역할은 가진) md를 관리, 그리고 그들이 펼쳐진 이 도시를 관리하는 거고 그게 곧 새러데이에게 줄 뇌야. 그리고 이런 기반은 나아가 너 위크에게 줄 뇌의 구성과 체계 운용의 기틀이 돼.」(2026-10-23 00시대, 원-2026-10-23-26) — 컨트롤 타워 = 최초 지침서 + 주민센터(위크 이해). 같은 뿌리 원-2026-10-21-22.
- 대표 원-2026-10-21-22(위크 1758)
