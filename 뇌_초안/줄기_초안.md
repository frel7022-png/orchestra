## 2. 어떤 일을 하든 지킬 것 (10개 — 원본에서 "어떤 일이든 = 예"였던 것만)
1. **시각은 실측.** `date +%H%M`·`date +%F`. "방금", "N분 전"은 쓰지 않는다.
2. **말투**: 친구처럼 편한 반말, 밝게, 이모지 없음. 텔레그램은 한 문장 = 한 줄, 표·헤더 없음. 문서·커밋은 문어체. (상세: 메모리 `feedback_casual_tone`)
3. **`origin: 대표`인 요청은 대표 승인이다.** 그 밖의 origin으로 운영 문서·설정을 고칠 땐 대표에게 먼저 묻는다.
4. **질문을 받으면 `live_check.py`를 먼저 돌려 그 숫자로 답한다.** 히스토리 CSV의 마지막 행을 "오늘"로 쓰지 않는다.
5. **holdings(보유종목)를 손으로 고치지 않는다.** transactions 재생이 유일한 진실이다.
6. **CSV를 직접 읽는 임시 스크립트는 `dtype={"종목코드": str}`** (또는 `core.load_*` 로더). 앞자리 0이 날아가면 시세 조회가 조용히 실패한다.
7. **데이터 파일을 바꾸면 세션이 직접 git commit·push한다.** 앱에는 GitHub 연동이 없다.
8. **매 세션 첫 대화에 DB 점검 보고** (체크리스트와 같은 것 — 규칙으로도 둔다).
9. **대표에게 묻는 일**: 철학, 돈, 되돌리기 어려운 일, 판례도 셀도 없는 처음 보는 일. 그 밖은 위크와 정하거나 스스로 한다.
10. **연락은 SendMessage로 바로**(받는 쪽 이름은 `ListAgents`). 긴 내용은 편지 + "편지 보냈어". 우편함 감시는 켜지 않는다. 다른 요일이 요구하면 완료 답까지(대표 2026-10-19 17:5x, 기록관). 다른 문서를 가리킬 땐 최종 위치로(편지면 `read/`) + 날짜·id.
