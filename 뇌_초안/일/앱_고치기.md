  - 요청이 대표가 아니면(다른 요일·위크) 운영 문서·설정은 먼저 확인한다(지침서 1절 origin).
  - 리스키한 수정 전 안전망 = **git 태그 + `Desktop/backup/old_brain_날짜/` 스냅샷**(대표 마-2 찬성, 2026-10-22 `old_brain_2026-10-22` 실제로 뜸 — memory·new1_local·sessions·supabase·scheduler). 리스키한 수정이면 그 전에 한 벌 더 뜨고 날짜를 적는다. 〔10-22 위크 결정, 대표 위임〕
- **멈추고 묻는다**:
  - **숫자 정의가 바뀌는 수정**(분모·기준일·문턱·"당일" 뜻)이면 멈추고 묻는다. 예: 당일 % 정의(Q-2), Fishing −3%(세팅). 묻는 건 새러데이가 먼저 숫자를 바꾸려 할 때다. 결정되면 숫자는 세팅 한 줄, 정의는 그 잣대 사무실과 같은 커밋으로.

## 권한
- **바로 해도 됨**
  - **단 대표가 직접 숫자를 준 경우**("Fishing 4%로 해")는 그게 답이다 — 데이터센터 게시판(대표가 정한 것) 흐름 4대로 바로 반영(범위가 애매하면 그것만 되읽기).
- **안 함**
  - **대표가 바꾸라고 하지 않은 칸**은 손대지 않는다. 고치다 본 하드코딩·중복은 "왜 문제고 고치면 뭐가 좋아지나"를 먼저 말하고 승인 뒤에 고친다.
  - **수동 입력 UI는 만들지 않는다** — CSV 업로드가 유일한 입력(대표 「CSV로만 관리할 거라 필요 없다」, 두 번 지움). 고칠 일은 CLI 스크립트.
  - 옛 코드를 보고 진단하기 · 빈 커밋으로 재배포 유도하기(아래 확인 "배포").
- **대표 몫**: D에서 고칠지 · 숫자 정의 · meritz 이식 승인 · Reboot app 누르기 · 큰 구조(Plan Mode 뒤 안 셋 중 고르기).

## 확인
> 다 쓴 뒤 스스로 맞춰 보는 목록(원-2026-10-29-02 — 일 md에만, 멈춤 · 권한과 같이).
- 계산을 고쳤으면 `tests/test_portfolio_core.py`에 케이스를 더하고 `pytest tests/ -q` 전체를 돌린다. AppTest는 CSS·픽셀을 못 본다.
- 픽셀·배치는 **Playwright 390px**로 실제로 본다 — 눈대중 금지.
- 사무실을 같이 고쳤으면 `brain_log.py links`·`heads`(반사 6). 코드 이름표(`@뇌`)를 옮겼으면 links가 잡는다.
- 로컬에서 `streamlit run app.py`로 보려면 `.streamlit/secrets.toml`이 **있어야** 한다(빈 파일이어도 됨 — 없으면 `StreamlitSecretNotFoundError`, 옛 §6-1-1). 시크릿 값은 출력에 찍지 않는다(반사 5). 〔v1 ⑦〕
- 숫자·정의(대표 결정)가 든 코드 커밋이면 메시지에 `셀: 사무실명` 또는 `셀: 없음(→ 위크 대조표)`(뇌관리 게시판 — 도시 운용 원칙, 10-22 채택).
- 계산을 바꿨으면 **같은 순간 옛 코드와 나란히** 돌려 차이를 bp로 적는다 — 옛 코드는 `git show HEAD:파일`로 꺼내 import(10-22 bench·picks·레벨 대조가 이 방법, 커밋 메시지에 "최대 차이 N bp"). 〔옛뇌 앎 전수 목록 다 — new1-35〕
- 커밋 전 `git status` — 데이터 파일이 안 바뀌었나(테스트는 10-21부터 실데이터를 안 건드리지만 습관). `git add`는 파일 이름을 정확히.
- 배포: `Updated app!` + 트레이스백 없음이면 기다린다(하루까지 늦을 수 있음). 트레이스백인데 로컬에서 재현이 안 되면 대표에게 **Reboot app**을 부탁한다. 빈 커밋으로 재배포를 유도하지 않는다(일과 게시판 — 기록 올리기).
- 보고: 무엇을 고쳤나 · 테스트 결과(숫자) · 커밋 id · 배포 지연 가능성.
