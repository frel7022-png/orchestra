# 휴장일 달력

## 설명
- **무엇을 내놓나(끝까지)**: 휴장일을 `krx_holidays.csv` 하나로 미리 안다 — 경고가 뜨면 지난 평일을 코스피 일별시세로 실측하고 남은 해는 KRX 공지(예정)로 채워 확인일을 고치고, 테스트 → 커밋(`셀: 정비실/휴장일`) → push. 묻기만 하면("다음 휴장일?") 달력에서 답한다. 가짜 행 삭제는 대표 확인 뒤.
- **언제 시키나**: 매일 점검(check_daily_db) 첫머리에 `[휴장일 달력]` 경고가 뜰 때 · 매달 첫 거래일 · 새 휴장 공지(선거·임시 휴장)를 들었을 때 · 휴장일에 가짜 행이 보일 때. 부르는 말: 휴장일, 달력, 명절, 대체공휴일, 임시 휴장, 다음 휴장일, 장 열려.
  - **"다음 휴장일 언제?"·"오늘 장 열려?"**(묻기만) → `krx_holidays.csv`에서 오늘 뒤 첫 줄(주말은 요일로 — 날짜는 `date`로 잰다), 오늘이 휴장인지는 달력 판정 함수로(정비실 게시판 — 휴장일). 달력 확인일이 오래됐으면(경고 a) "달력은 MM-DD 확인분 기준"을 붙인다. 고치는 일이 아니라 답하는 일이라 아래 갱신은 안 탄다. 〔빈 세션 시험 13 G1 말2〕
  - **경고 (a)** "휴장일 달력 확인할 때" — 확인일 **최댓값**이 **35일** 넘게 지남(확인일이 하나도 없어도 뜸 — 숫자는 세팅). → 갱신. [새]
  - **경고 (b)** "내년 휴장일 넣을 때" — **12월 한 달 동안만** 다음 해 휴장일이 0줄이면. 1월로 넘어가면 새해 줄이 없어도 안 뜬다 → **1월 첫 출근 점검 땐 눈으로 한 번**. → KRX 공지로 내년 평일 휴장 넣기(전부 예정). [새]
  - 경고 (c) "krx_holidays.csv를 못 읽음" → 파일 깨짐·없음 — 달력으로 못 거르는 상태라 바로 고친다(실시간 판정 보조 그물만 남음). [새]
  - **새 휴장 공지**(선거 등) → 그 날짜 한 줄(예정) 바로. [재구성]
  - **가짜 행이 보임** → 달력 이전 사고인가, 달력에 빠진 날인가(정비실 게시판 — 휴장일 반문 질문). [새]
- **얻을 것과 찾을 곳**(순서 아님 — 어디부터 볼지, 그 게시판에서 어느 사무실을 고를지는 그때 판단, 원-2026-10-27-12 · 위크 1027 「길에서 직접 정보를 빼고 게시판을 보고 판단」)
  - **언제 무엇을 갱신하나**(월 1회 · 실측/예정 · 누가 이 달력을 보나 · 사고 모음) → 정비실 게시판(휴장일)
  - **경고가 어디서 뜨나** → `출근_점검.md`
  - **달력을 읽는 코드** → 설계도실 게시판(인프라 크론)
- **갱신할 때 담을 것** (순서 아님)
  - 지난 확인일 이후 평일 — **코스피 일별시세에 없는 평일 = 실측 휴장**. 확인 칸 "실측(…)", 확인일 = 오늘. [새]
  - 남은 해 평일 휴장은 KRX 공지로 "예정". 실측으로 바뀌면 그 줄을 고친다(줄을 지우지 않음). [새]
  - **이미 있는 줄도 확인일을 오늘로**(경고 (a)는 확인일 최댓값으로 재기 때문 — 새 휴장이 없어도 한 줄은 갱신해야 경고가 꺼진다). [재구성]
  - 테스트 → 커밋(`셀: 정비실/휴장일`) → push. [새]

## 멈춤
- ⛔ **DB·히스토리의 가짜 행 삭제는 대표 확인 뒤** — 지우기 전 행 수를 찍고 백업(10-06 가짜 10/5 행 180개 + market_flow 0 행 2개 / 10-21 추석 복제 행 360개 + 0 행 4개, 둘 다 대표 확인 뒤). [기억] / 10-21 [새]
- 8/27 같은 "평일인데 데이터 없음"은 **휴장이 아니라 cron 미실행**일 수 있다 — 달력에 넣지 말고 출근 점검(빠진 날 메우기)으로. [기억]

## 권한
- **바로 해도 됨**: 달력 갱신(실측 · 예정 · 확인일) · 새 휴장 공지 한 줄 · 깨진 파일 고치기(경고 c) · 테스트 · 커밋 · push.
- **안 함**
  - 휴장일 market_flow 순매수 **0을 오류로 보기** — 0은 오류가 아니다(9/24 추석 실측 — 새 API가 휴장일에 "0"을 줌). 0 행을 "빠진 데이터"로 오해해 다시 받지 않는다 — 단 그날 행 자체가 생긴 게 가짜면 멈춤으로. [기억]
  - 예정 줄을 지우기(실측으로 바뀌면 그 줄을 고친다).
  - meritz·써스데이 레포에 달력 이식 — meritz·써스데이는 아직 이 달력을 안 본다, 이식은 그쪽 레포 일. 새러데이가 해도 되는 건 대표가 맡긴 범위만(위 D1 정정). 〔대기: meritz 이식 시점 — 대표〕 [새]
- **대표 몫**: 가짜 행 삭제 확인 · meritz 이식 시점.
