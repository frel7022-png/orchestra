# 지금 숫자로 답하기

트리거: 대표가 "지금 어때?", "오늘 계좌는?", "코스피 몇이야?"처럼 오늘·지금의 숫자를 물을 때. 텔레그램으로 깨워진 질문
한 문장: 지금 숫자는 히스토리 CSV 마지막 행이 아니라 `live_check.py`를 먼저 돌려 그 숫자로 답하고, 언제 기준인지(장중·확정·휴장)를 첫 줄에 붙인다.
상태: 시험판(형식 B) · 마지막 확인 2026-10-20
이 셀 안 (게시판 → 이 머리 → 필요한 칸만 펼친다):
- 절차 — live_check → 기준 시각 확인 → 답(텔레그램은 한 문장 한 줄)
- 멈출 때 — 보유 수량이 오래된 매매일지 기준일 때
- 끝났다는 확인 / 산출물 — 대화 답 하나(파일 안 남김)
- 금지 — CSV 마지막 행을 "오늘"로, 앱 화면 값을 그대로 옮기기
- 무엇으로 재나 — `live_check.py`(`live_snapshot`), `friend_brief.py`(친구 창구)

## 꼬리표
종류: 기능
옛 이름: claude.md §2 `live_check.py` 설명, §6-9 휴장일 "오늘"

부르는 말: 지금 어때, 오늘 숫자, 라이브

## 절차
1. `python live_check.py` (무엇을 어떻게 재는지는 `../관측소/주가_변화.md`).
2. 첫 줄의 기준을 읽는다: 장중 / 장마감 / 휴장(마지막 거래일 종가 기준).
3. 사실을 읽은 뒤 → 눈 셋의 질문을 던진다(`../바라보는_눈/_게시판.md` — 이때 시장은? 외인은? 분모·기간을 바꾸면?). 기억에 맡기지 않고 이 길에 박아 둔다(대표 원-2026-10-20-13).
4. 그 숫자로 답한다. 텔레그램이면 한 문장 = 한 줄, 표·헤더 없음(줄기 §2-2).
5. 비교 질문(시장 대비)이면 무엇과 견줬는지 붙인다 → `../가치척도/누구와_싸우나.md`.

## 멈출 때
- 마지막 매매일지 반영이 며칠 전이다 → "보유는 ○일 반영분 기준"을 말하고, 대표가 매매일지를 넣었는지 묻는다.

## 끝났다는 확인 / 산출물
- 대화 답 하나. 임시 계산 파일을 만들었으면 지운다.
