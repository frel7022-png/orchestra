# 매매일지 반영

트리거: 대표가 "넣었어"·"올렸어"(todaytrans/에 매매일지 CSV). 지난 날짜 매매일지를 다시 넣을 때. 예탁금 이용료(입금)가 들어왔을 때
한 문장: 매매일지는 그날 하루 전체의 누적이라 같은 날짜를 통째로 바꿔 넣고, 반영 → 확인 → 외인 DB 점검 → push를 묻지 않고 끝까지 한다.
상태: 시험판(형식 B) · 마지막 확인 2026-10-20
이 셀 안 (게시판 → 이 머리 → 필요한 칸만 펼친다):
- 절차 — 날짜순으로 ingest → 결과 확인(보유 수·예수금·정합성) → 코드 없는 종목 → DB 점검 → commit·push
- 멈출 때 — 파싱 실패, 보유 수가 크게 이상, 코드가 끝내 안 풀림, git 충돌
- 끝났다는 확인 / 산출물 — 정합성 OK, 커밋 하나, 대표에게 날짜별 매수·매도 건수
- 금지 — holdings 손으로 고치기, append, dtype 없이 종목코드 읽기, 섹터를 인라인으로 고치기
- 자주 틀린 곳 — lock-step 재발 1~7(당시 사건)
- 무엇으로 재나 — `ingest_daily.py`, `check_history_alignment`, `fix_sector.py`, `cfg_ask.py`

## 절차
1. 파일 이름(예: `todaytrans/1020.csv`)에서 날짜를 읽는다. 여러 날이면 **오래된 날부터** 차례로.
2. `python ingest_daily.py todaytrans/파일 YYYY-MM-DD` — 그 날짜의 기존 반영분을 지우고 이 파일로 바꾼 뒤 재계산(체크포인트 경로, 최근 3일은 매번 다시 재생).
3. 확인: 보유 종목 수·예수금·`[정합성 OK]`(asset·sector·index·bigcap 마지막 날짜가 같은가). 출력이 깨져 보이면 `check_history_alignment(날짜)`를 따로 부른다.
4. 코드 없는 종목이 있으면 `core.refresh_all_prices()`로 채운다(ingest가 매번 한 번 돌리지만 확인). 새 종목은 ingest 끝에서 watchlist에 자동 편입.
5. 외인 DB 점검 → `출근_점검.md` 절차 1~3.
6. 데이터 파일만 묶어 commit·push → `기록_올리기.md`.
7. 대표에게: 날짜별 매수·매도 건수, 보유 수, 예수금. 장중 파일이면 "장중까지"라고 밝힌다(마감본이 오면 같은 날짜로 다시 넣는다).
8. `python cfg_ask.py 날짜` — 그날 새로 산 종목 중 직전 **3거래일** 아침 리포트에 나온 것만 찍힌다. 있으면 그 한 줄을 보고 끝에 그대로 붙인다(하루 한 줄로 묶음, 종목 옆 괄호 = 어느 리포트 — "외인 보고 산 것"과 Fishing·Up/Down 보고 산 것을 대표가 가르게). 대표가 짚은 종목만 태그하고(`../수급/외인_매수_복기.md` 절차 1), 답이 없으면 태그하지 않는다(추측 태그 금지). 없으면 묻지 않는다(위크 회의 2026-10-20, 인투셀 태그 빠짐).
- 예탁금 이용료: `transactions.csv`에 `구분=입금`, `수량=1`, `단가=금액`, `메모=예탁금이용료` 한 줄 → 재계산(이 행은 매매일지 재반영으로 안 지워진다).

## 멈출 때
- 파싱 실패, 보유 수가 크게 이상, 코드가 끝내 안 풀림, git 충돌 — 이때만 대표에게 묻는다. 그 밖엔 묻지 않고 끝까지(대표 지시).
- `[정합성]`에 뒤처진 파일이 있으면 어느 날짜가 비었는지 보고 그 날짜만 확정 종가로 채울지 판단.

## 끝났다는 확인 / 산출물
- 정합성 OK + 데이터 커밋 하나(메시지에 날짜들) + 대표 보고 한 덩어리.

## 금지
- todaytrans 스테이징·세션이 push·backup 폴더 안전망 흐름은 메모리 `project_workflow` 그대로.
- holdings(보유)를 손으로 고치지 않는다 — transactions 재생이 유일한 진실(줄기 §2-5).
- 같은 날짜를 append하지 않는다 — 누적이라 중복된다(§1-2, 네이버 1주 → 3주).
- 임시 스크립트로 종목코드를 읽을 때 `dtype={"종목코드": str}` 없이 읽지 않는다(줄기 §2-6).
- 섹터를 인라인 스크립트로 고치지 않는다 → `python fix_sector.py 종목명 섹터`(세 파일 + 체크포인트 동시).
