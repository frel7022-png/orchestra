# 일일 평가 (Claude's Read)

## 설명
- **무엇을 내놓나(끝까지)**: 일일 평가는 대표가 시킬 때만, 16:00 이후 그날 숫자로 서술과 별점을 쓰고, 파일엔 최신 1건만 남긴다. `claude_daily_notes.csv` 한 행 + 커밋 — 앱 Today's Take 밑에 보인다.
- **언제 시키나**: 대표가 "Claude's Read 써"·"오늘 평가 써"라고 할 때만. 부르는 말: Claude's Read, 일일 평가, 오늘 평가, 별점.
- **얻을 것과 찾을 곳**(순서 아님)
  - 이 일의 길 = `../일/평가.md`(R·W 두 문, 쓰는 꼴·멈춤은 거기 — 2026-10-22 밤 반영). 여긴 절차·저장 규칙.
  - 무엇으로 재나 — `daily_stats.py`, `load_claude_notes`.
  - daily_stats 줄의 뜻 → 아래 "daily_stats 줄 → 읽는 사무실"(대응표).
- **걸음**
  1. 시각 확인 — 16:00 KST 이후인가(그 전이면 멈춤). 왜 16:00인지는 `../데이터센터/관측소/주가_변화.md` 함정 칸.
  2. `python daily_stats.py [YYYY-MM-DD]` — 그날 수치를 덤프. **meritz엔 daily_stats.py가 없다** — meritz 평가는 숫자를 즉석 계산해서 쓴다(meritz 레포 `portfolio_core`로). daily_stats는 both_accounts를 안 읽는다 — 머리 docstring의 "append·sync 뒤에 실행"은 옛 문구다.
  3. 서술 3~5문단 + 별점 ★1~5(보수적, 대부분의 날 ★★ — 코드 저장 형식은 "0~5 정수, 보수적, 중간=2", `portfolio_core.load_claude_notes`). 서술 순서는 시장 판정 → DC/UC → 자금 배치 → 실현손익 → 물타기·P&L 한 줄 → 총평 + 별점 이유(옛 §6-22 목록, 마지막 줄 형식은 자유 — 세션 값·출처 없음). 무엇을 어떻게 읽나(시장 판정·DC/UC·자금 배치)는 `../바라보는_눈/견주는_법.md`·`../가치척도/누구와_싸우나.md`.
  4. `claude_daily_notes.csv`의 이전 행을 지우고 새 행 하나만.
  5. `기록_올리기.md` 절차로 commit·push.
  - 각 앱의 평가는 자기 계좌만(new1은 Orchestra, meritz는 Orchestration) — 서로 견주지 않는다.
- **꼴**
  - **별점 단계별 뜻**(Claude's Read — 보수적, 중간 = ★★, 반 개 없음): ★ = 시장보다 확연히 열위 · ★★ = 시장과 비슷하거나 조금 열위(대부분의 날 기본값) · ★★★ = 뚜렷한 선방 + 무난한 자금 배치 · ★★★★ = 강한 방어 + 익절 확보 + 좋은 배치 · ★★★★★ = 드묾(하락일 거의 안 빠짐, 또는 상승일 시장 이상 참여 + 매매가 다 맞아떨어진 날). [옮김] 옛 claude.md 1485–1487 (§6-22)
  - 화면: new1은 요약 카드 Today's Take 바로 밑, meritz는 요약 카드 밑. Claude 마크(오렌지 `#D97757`) + 별 + 날짜, 네이티브 `<details>`라 눌러도 rerun 없음, 펼치면 오늘 것만(`ui_portfolio_tab._claude_read_html`, 옛 claude.md §6-22).

## 멈춤 (멈출 때)
- 16:00 전 → 16:00 이후로 미룬다(이미 썼으면 16:00 뒤 다시 돌려 덮어쓴다).
- 그날 매매일지가 장중본뿐 → 마감본이 오면 쓴다고 대표에게. 마감본 = 15:30 이후 받은 매매일지다 — 16:00 규칙은 시세(확정 종가) 때문이라 매매일지 시각과는 별개(세션 값·출처 없음).

## 권한
- **바로 해도 됨**
  - **DC/UC는 여기(Claude's Read)와 주간 평가에서 쓰는 말이다** — 대표 「DC/UC는 보통 클로드리드나 주간평가에서 내 주식을 시장과의 평가를 다룰 떄 쓰여. 매일 주는 매매리포트 관련에 DC/UC는 들어갈 일이 없어.」(원-2026-10-21-10). 날 수(방어·참여)와 Σ/Σ 값을 같이, 숫자는 문장 안에 — 견본은 아래 적용 예(2026-10-12 Read).
