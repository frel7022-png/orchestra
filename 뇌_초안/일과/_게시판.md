# 일과 — 1층 게시판 (기능 빌딩, 가칭)

이 빌딩은 **매일·매주 정해진 일을 어떤 순서로 끝내나**를 다룬다. 셀은 전부 기능 셀(형식 B: 절차 / 멈출 때 / 끝났다는 확인 / 산출물 / 금지 / 자주 틀린 곳). 판단(무엇을 볼까)은 분석 빌딩, 재는 법은 관측소.
연락 규칙(우편함·SendMessage·감시 끔)은 어떤 일을 하든 걸려서 여기가 아니라 줄기 §2에 있다.

| 언제 펼치나 | 사무실 |
|---|---|
| 세션 첫 대화, 하루를 시작할 때 — DB가 빠짐없이 쌓였나 | `출근_점검.md` |
| 대표가 "넣었어"(매매일지 CSV), 지난 날짜 매매일지를 다시 넣을 때, 예탁금 이용료가 들어왔을 때 | `매매일지_반영.md` |
| 평일 아침 리포트 4종(09:30 생성 → 총평 → 다시 생성), 대표가 "리포트 써" | `아침_리포트.md` |
| 금요일 장 마감 뒤(휴장이면 목요일) 주간 리포트, 대표가 "Claude's Read 써" | `주간_리포트.md` |
| 대표가 "지금 어때?"처럼 오늘 숫자를 물을 때 | `지금_숫자로_답하기.md` |
| 데이터 파일을 바꾼 뒤 올릴 때, VIP 기준가를 넣을 때, 배포가 화면에 안 보일 때 | `기록_올리기.md` |

헷갈릴 때 고르는 법:
- 숫자를 **만드는** 일(반영·생성) → 매매일지 반영 / 아침 리포트
- 숫자를 **말하는** 일(대표 질문) → 지금 숫자로 답하기
- 만든 걸 **남기는** 일(커밋·push·두 레포) → 기록 올리기
