# 외인 매수 복기 — 외인 보고 산 건 맞았나

트리거: 대표가 "외인(리포트) 보고 X 샀어"라고 할 때. 주간 리포트 때 `cfg_ask.py --week`가 빠진 후보를 찍었을 때. 대표가 "그때 외인 보고 산 거 어떻게 됐어?"·옅은 빨강 카드를 물을 때. 금요일 주간 리포트
한 문장: 대표가 외인을 보고 직접 산 매수를 태그해 두고, 사이클이 끝나면 얼마나 맞았는지(사이클 결과·사례 — 판정 단위는 사이클, 2026-10-21)를 쌓아 외인 분석을 다듬는 재료로 꺼내 본다.
상태: 시험판 · 마지막 확인 2026-10-20

## 꼬리표
종류: 기능(관점을 다듬는 재료 쌓기)
옛 이름: CFG 태그, 옅은 빨강 카드, CFG vs Others, 케이스북
저장고: `cfg_tagged.csv`(종목명·태그일·메모) / `cfg_track/`(summary.csv·events.json, `cfg_track.py`) / `casebook/casebook.csv`·`cases.json`(`casebook.py`, 사이클 하나 = 사례 하나) / Statistics "CFG vs Others"(`compare_cfg_cycles`, 사이클) / `casebook/study_events.csv`(관심종목 전체 이벤트 스터디 10-02 0호·10-06 1호, `casebook_study.py` — 쉬는 저장고)
부르는 말: CFG로 샀어, 외인 보고 샀어, 빨간 카드, 케이스북, 맞았나

## 절차
1. **태그**: 대표가 "외인 리포트 보고 X 골랐어"라고 말해 주는 게 원칙(대표 원-2026-10-20-20 — 세션이 고르지 않는다). `cfg_ask.py --week`는 주간 리포트 때 빠진 걸 줍는 보조(매일 묻지 않는다). 대표가 짚으면 `cfg_tagged.csv`에 한 줄 — 태그일 = **그 매수일**, 메모 = 어느 리포트·무엇을 보고. 카드가 옅은 빨강 + Holdings 맨 위가 된다(`../데이터센터/보유_카드.md`).
1-1. **추적(매일 아니어도 리포트·질문 때마다)**: `python cfg_track.py` → `cfg_track/summary.csv`(태그 한 줄 = 카드: 상태·매수횟수·태그 뒤 물타기·결과%·태그가 대비%·외인 태그일→지금/종료 pp)와 `events.json`(매수·물타기·매도마다 그날 외인 보유율). 매수부터 물타기, 마지막 매도까지 사이클째로.
2. **사이클이 끝나면**(전량매도): Statistics "CFG vs Others"가 **사이클 단위**로 자동 집계(`compare_cfg_cycles`) — 태그된 매수가 든 사이클 = CFG, 나머지 사이클 = Others. 단위의 지금 값은 `../가치척도/현행값_집.md`.
3. **케이스북 갱신**: `python casebook.py` — 매도 끝난 사이클마다 진입 전 하락·외인 변화, 보유 중 흐름, 매도 때 외인 방향, 매도 뒤 주가를 한 줄로(CFG 태그 열 포함). 주간 리포트 때 돌린다(`../일과/주간_리포트.md`).
4. **꺼내 보기**: 대표가 물으면 `casebook/casebook.csv`에서 `CFG` 열로 걸러 "얼마나 맞았나·효과 몇 %"를 CFG vs Others와 같이 말한다. 하나만 볼 땐 그 종목 행 + `python eye_card.py 종목명`(그때 바다).

Others 쪽만 **매수 건 235개(평균 +5.00%·승률 88.9%) → 사이클 159개(평균 +4.61%·승률 94.3%)**. 열린 CFG 3개(인바디·와이지-원·우리금융지주)는 둘 다 채점 밖. 와이지-원(20번 매수 중 태그 전 13번)이 끝나는 날부터 두 방식이 갈린다. 코드 변경은 위크·대표 확인 뒤.
