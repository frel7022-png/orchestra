# 수급 — 1층 게시판

이 빌딩은 **누가 사고 누가 팔았나**를 다룬다. 유니버스 1층(외인·기관)이 남긴 흔적을 2층(new1)이 읽는 자리다.
대표 철학: 외인이 먼저 모으고 주가가 빠질 때, 우리는 더 유리한 자리에서 늦게 들어간다(메모리 `user_investment_strategy`, 10-16 대표).

| 언제 펼치나 | 사무실 |
|---|---|
| 외인 보유율·순매수 숫자로 무언가를 판단하거나 추천 근거로 쓸 때. 가격과 외인이 반대로 움직일 때. 외인이 나간다고 판단하려 할 때 | `외인_판단.md` |
| 폭락일·급락 종목·평지 구간에서 "누가 샀나"를 볼 때. 외인과 기관 순매수를 합치려 할 때 | `누가_받았나.md` |
| 대표가 "외인 보고 X 샀어"·`cfg_ask.py` 후보가 나왔을 때. 그 매수가 맞았나 꺼내 볼 때(옅은 빨강 카드·CFG vs Others·케이스북) | `외인_매수_복기.md` |
| 빠지던 종목이 멈춘 것 같을 때. 거래량이 평소와 달라 보일 때. Basecamp 순위를 해석할 때 | `바닥과_물량.md` |
| **"X 언제 명단에 들어왔어?"·"며칠째야?"·"언제 빠졌어?"·진입가** — 명단 들고남은 쌓이는 기록에서 센다(리포트 한 장으론 못 셈) | ② Link 명단 `link_sample/roster.csv`(날짜·순위·단계·진입일·진입가, 10-02부터) · "따로 관리" `link_sample/pinned.csv`(고정일·고정가·고정외인) · ③ 진짜 CFG `morning_report/cfg_log.csv`(10-02부터) · ③ 칸 순위·거리 `morning_report/cfg_rank.csv`(**10-26부터**) — 읽는 법은 `외인_판단.md` |

헷갈릴 때 고르는 법:
- 외인 **혼자의** 흐름(비중·누적·이탈) → 외인 판단
- 그날·그 구간 **외인 vs 기관**, 누가 받았나 → 누가 받았나
- **가격 모양 + 거래량**(빠짐 → 평지 → 물량) → 바닥과 물량
- 대표가 외인 보고 **이미 산 것**의 결과 → 외인 매수 복기 (새러데이가 권한 것은 `../추천/추천_사례집.md`)
