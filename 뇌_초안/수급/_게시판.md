# 수급 — 1층 게시판

이 빌딩은 **누가 사고 누가 팔았나**를 다룬다. 유니버스 1층(외인·기관)이 남긴 흔적을 2층(new1)이 읽는 자리다.
대표 철학: 외인이 먼저 모으고 주가가 빠질 때, 우리는 더 유리한 자리에서 늦게 들어간다(메모리 `user_investment_strategy`, 10-16 대표).

| 언제 펼치나 | 사무실 |
|---|---|
| 외인 보유율·순매수 숫자로 무언가를 판단하거나 추천 근거로 쓸 때. 가격과 외인이 반대로 움직일 때. 외인이 나간다고 판단하려 할 때 | `외인_판단.md` |
| 폭락일·급락 종목·평지 구간에서 "누가 샀나"를 볼 때. 외인과 기관 순매수를 합치려 할 때 | `누가_받았나.md` |
| 빠지던 종목이 멈춘 것 같을 때. 거래량이 평소와 달라 보일 때. Basecamp 순위를 해석할 때 | `바닥과_물량.md` |

헷갈릴 때 고르는 법:
- 외인 **혼자의** 흐름(비중·누적·이탈) → 외인 판단
- 그날·그 구간 **외인 vs 기관**, 누가 받았나 → 누가 받았나
- **가격 모양 + 거래량**(빠짐 → 평지 → 물량) → 바닥과 물량

자주 같이 가는 길:
- 바닥과 물량 → 누가 받았나 (평지 거래량이 크면 받은 손부터)
- 누가 받았나 → 외인 판단 (외인이 받았으면 그 뒤 외인 상태를 따라감)
- 외인 판단 → `../기준과비교/상대적_가치.md` (외인 변화를 %로 보려 할 때 분모부터)
- 외인 판단 → `../기준과비교/판정은_기간에_묶여_있다.md` (외인 이탈로 픽을 판정하려 할 때)
