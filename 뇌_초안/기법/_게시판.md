# 기법 — 1층 게시판

이 빌딩은 **새러데이가 대표의 반례에서 직접 만들어 낸 분석 방법**을 모은다(규율 v0.8 §15, 대표 2026-10-19: "이런 기법을 머리에 새기는 거지. 내가 무엇을 분석해 봐 하면 저기 가서 비슷한 걸 찾아보던가").
관점 셀이 "무엇을 어떻게 볼까"라면, 기법 셀은 "그걸 어떤 방법으로 가르고 재나"다. 칸: 트리거 / 기법 한 줄 / 탄생 판례 / 쓰는 법 / 무엇으로 재나 / 한계 / 비슷한 기법.
