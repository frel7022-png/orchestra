## 패널마다 무엇을 그리나
| 패널 | 무엇 | 함수 |
|---|---|---|
| Account : Index (2장 캐러셀) | ① 코스피·코스닥·혼합지수·내 주식(Rs)·내 계좌 누적 선 + 표(누적·5일·당일) ② 하락·상승·even 캡처 표 + 일별 캡처 막대 | `compute_index_vs_account`(`_cap_stats`), `_render_iva_panel` |
| SamHYnix extracted | 같은 패널, 코스피 다리만 삼성·하이닉스 제외 | `synthetic_kospi_ex_bigcap` |
| Sour Grapes | SH 바스켓(그 셋만) vs 내 계좌 두 줄 | `synthetic_kospi_sh_only` |
| KOSPI 2-Track | 일반 코스피 vs 제외 코스피, 실제 지수 포인트 | 위와 같음 |
| VIP vs Orchestra vs Orchestration | 펀드·new1·meritz 8/14 리베이스 세 선 | `compute_vip_vs_orchestra`, `fetch_peer_account_snapshot` |
| P&L Actions | FA·MO·MA 표 + 도넛 + 상태표 + Watering 상세 | `compute_pnl_actions`, `_all_cycles`, `_cycle_bucket` |
| Pit Stop(요약 카드 안) | Cost Basis·Orchestra Refill·Index Refill·Surplus | `seed_engine_series`, `blended_benchmark_cum` |
| 일일거래 요약 FA 줄 | Total·FA·MA·MO 비율 | `compute_fa_win_rate` |
| 누적 요약·캘린더 | 누적 매수/매도 건수·일평균 건수, 달별 실현손익 | `ui_transactions_tab` |
| Price Brackets | 매도 완료 사이클 진입가 구간(빨강) vs 보유 평단가 구간(파랑) 짝 막대 | `price_bracket_distribution`, `holdings_price_bracket_distribution` |
| Top Traded | 매도횟수 순(동률 진입가 높은 순), 작은 정리 거래 제외 | `top_traded_stocks` |

## 공유
- 혼합지수 가중합은 한 공식(`compute_index_vs_account` 안 `_bench_on` = `blended_benchmark_cum`) — 앱 전체에서 같은 정의.
- 캡처의 하락·상승·even 날 나누기 정의는 `../관측소/바다.md` "날의 바다", 읽는 법은 `../가치척도/상대적_가치.md`.

## 금지
- 패널마다 벤치를 따로 계산하지 않는다(위 공식 하나).
- 보유 중(미확정) 사이클을 통계에 섞지 않는다 — Statistics·FA·Top Traded 다 매도 완료 사이클만(`../가치척도/판정은_기간에_묶여_있다.md`).
- 현재가로 매도 판단의 승패를 매기지 않는다 — Selection Index 은퇴(경위 `../ARCHIVE/§6-32.md`).
- 이 패널들에 설명 캡션 금지(`화면_지도.md`).
