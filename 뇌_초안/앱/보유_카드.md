## 카드에 무엇이 있나
- **종목명 아래 배지 줄**(`dividend-row`): 배당수익률(구간별 색, `_dividend_badge_html`) + 외국인 보유율(`holding_foreign_map`, 세션 1회 조회). 배당은 캐시에 없는 종목만 한 번 긁는다(`refresh_dividend_yields`).
- **손익 셀**: 이익 종목만 최초 진입일·보유 거래일수 배지 + 세금 차감 후 실현액(손익 − 평가금액×fee_rate) 병기.
- **카드 색**: CFG 태그 사이클 = 옅은 빨강(맨 위 고정) > 물타기(매수 2회 이상) 중 현재가 ≥ 최초진입가 = 옅은 파랑 > 평단 −0.5% ≤ 현재가 < 최초진입가 = 옅은 녹색(평단 −0.5% 아래는 흰색, `watering_card_state`). 오늘 처음 보유 = 맨 위·종목명 초록.
  - 파랑의 뜻(대표 원-2026-10-20-20): 물타며 시드를 키웠는데 최초진입가 자리만 와도 익절 — 아무것도 안 했으면 못 버는 구간에서 번 것, 물타기 자체가 노리는 곳. 대체됨(2026-10-20): 2회 이상 + 현재가 ≥ 최초진입가 = 녹색 / 같은 날 녹색 = 평단 ±0.5%·그 위 흰색 → 흰색 구간 없앰(위크 추천에 대표 "응 너 판단대로해", 원-2026-10-20-22).
- **타이틀 옆**: (이익 수 / 손실 수), 등락률순 정렬 점(정렬 라디오와 독립).
- **WATERING 점** → 상세(아코디언, 하나만): 누적·이번 사이클 매수/매도 요약, 그래프(현재가 = DB 일별 종가, 평단가 = 계단선 `line_shape='hv'`, 매수 ▲·매도 ▼, 최초진입가 점선).
- 계산 함수: `_current_cycle_transactions` · `get_holding_trade_summary(_all_time)` · `get_holding_trade_points` · `get_holding_avg_price_path` · `get_stock_price_history_db`.

## 금지
- 평단가를 "총매수금 ÷ 총매수수량"으로 다시 계산하지 않는다 — 매도가 끼면 틀린다. holdings의 평단가(재생 결과)를 쓴다.
- 전량매도 이전 사이클을 그래프·요약에 섞지 않는다(`_current_cycle_transactions`).
- 배당 배지를 종목명 옆에 붙이지 않는다 — 항상 아래 줄. Fishing엔 배당 배지 없음.
- 카드 그래프 시세를 네이버에서 낱개로 부르지 않는다 — DB만, 없으면 두 점 직선.
