## 함정과 고치는 법
- **빈 줄 HTML 끊김**: `st.markdown(f"""…""", unsafe_allow_html=True)` 안에서 조건부로 비는 조각(`{a}{b}`)을 단독 줄에 두면, 다 비었을 때 그 줄이 공백만 남아 HTML 블록이 끊기고 뒤가 코드블록(원문 노출)이 된다. → 비는 조각은 **항상 내용이 있는 태그와 같은 줄에** 이어 붙인다(`{a}{b}<div class="always-here">`). 앞뒤 줄에 내용이 있어도 안전하지 않다.
- **expander 안 그래프 폭 0**: `st.plotly_chart`가 expander 안에서 폭 0으로 안 그려진다 → `components.html`(iframe) + plotly `responsive:true`. 리사이즈 루프(`Plotly.relayout`)는 넣지 않는다(렌더 프리즈).
- **카드 위 버튼**: 카드 높이에 영향을 안 주려면 `st.container(key=…)` + CSS `position:absolute`(`[class*="st-key-…"]`).
- iframe 안은 시스템 폰트·inline 색 — 앱 CSS가 안 먹는다.
